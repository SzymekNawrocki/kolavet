# Vercel + SSR Rollout Plan

## Goal
Deploy kolavet.pl on Vercel with hybrid SSR so that:
1. Keystatic CMS is accessible at `/keystatic` behind GitHub OAuth (no hardcoded password)
2. `/api/newsletter` POST endpoint works (MailerLite signup)
3. All existing static pages continue to render at build time (zero performance regression)

---

## Step 1 — Install Vercel adapter

Run in the project root:

```bash
npx astro add vercel
```

This will:
- Install `@astrojs/vercel`
- Patch `astro.config.mjs` automatically (adds `import vercel from '@astrojs/vercel'` + `adapter: vercel()`)

After the command, open `astro.config.mjs` and change `output` to `'hybrid'`:

```js
import { defineConfig } from 'astro/config';
import vercel from '@astrojs/vercel';
// ... other imports ...

export default defineConfig({
  site: 'https://kolavet.pl',
  output: 'hybrid',          // ← add this
  adapter: vercel(),          // ← added by npx astro add vercel
  vite: { plugins: [tailwindcss()] },
  integrations: [react(), markdoc(), keystatic(), sitemap()],
                              // ↑ remove isDev guard — Keystatic Cloud handles auth
});
```

> `output: 'hybrid'` keeps every page statically generated by default.
> Only routes that explicitly export `export const prerender = false` become SSR.
> Currently that is: `/api/newsletter` and the Keystatic admin routes.

---

## Step 2 — Re-enable Keystatic in production

In `astro.config.mjs` the integration is currently guarded:

```js
...(isDev ? [keystatic()] : [])
```

Remove the guard:

```js
keystatic()
```

Keystatic Cloud will handle authentication. The admin UI at `/keystatic` will require GitHub login — no unauthenticated access.

---

## Step 3 — Set up Keystatic Cloud project

1. Go to [keystatic.cloud](https://keystatic.cloud) → sign in with GitHub
2. Create a new project → link to the `kolavet` GitHub repo
3. Note the **team slug** and **project slug** (e.g. `michalina/kolavet`)

Update `keystatic.config.ts` storage:

```ts
export default config({
  storage: {
    kind: 'cloud',
  },
  cloud: {
    project: 'michalina/kolavet',   // team/project from Keystatic Cloud
  },
  // ... rest unchanged
});
```

## Step 4 — Environment variables

### Local dev (`.env.local`)

```env
# Keystatic Cloud OAuth
KEYSTATIC_GITHUB_CLIENT_ID=Ov23li...
KEYSTATIC_GITHUB_CLIENT_SECRET=...
KEYSTATIC_SECRET=<random 32-char string>

# MailerLite
MAILERLITE_API_KEY=eyJ...
MAILERLITE_GROUP_ID=123456789

# Google Analytics
PUBLIC_GA4_ID=G-XXXXXXXXXX
```

### Vercel dashboard

Add the same variables under **Project → Settings → Environment Variables**.
Mark `MAILERLITE_API_KEY` and `KEYSTATIC_GITHUB_CLIENT_SECRET` as **Sensitive**.

### How to get Keystatic OAuth credentials

1. GitHub → Settings → Developer settings → OAuth Apps → New OAuth App
2. Application name: `Kolavet CMS`
3. Homepage URL: `https://kolavet.pl`
4. Authorization callback URL: `https://kolavet.pl/api/keystatic/github/callback`
5. Copy Client ID → `KEYSTATIC_GITHUB_CLIENT_ID`
6. Generate secret → `KEYSTATIC_GITHUB_CLIENT_SECRET`
7. Generate random secret: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` → `KEYSTATIC_SECRET`

## Step 5 — Add the newsletter API endpoint

Create `src/pages/api/newsletter.ts`:

```ts
export const prerender = false;

import type { APIRoute } from 'astro';

export const POST: APIRoute = async ({ request }) => {
  const { email } = await request.json().catch(() => ({ email: '' }));

  if (!email || !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
    return new Response(JSON.stringify({ ok: false, error: 'Invalid email' }), { status: 400 });
  }

  const apiKey  = import.meta.env.MAILERLITE_API_KEY;
  const groupId = import.meta.env.MAILERLITE_GROUP_ID;

  if (!apiKey) {
    return new Response(JSON.stringify({ ok: false, error: 'Not configured' }), { status: 500 });
  }

  const body: Record<string, unknown> = { email };
  if (groupId) body.groups = [groupId];

  const res = await fetch('https://connect.mailerlite.com/api/subscribers', {
    method: 'POST',
    headers: {
      Authorization: `Bearer ${apiKey}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(body),
  });

  return new Response(JSON.stringify({ ok: res.ok }), { status: res.ok ? 200 : 500 });
};
```

## Step 6 — Deploy to Vercel

Option A — Vercel CLI:
```bash
npx vercel --prod
```

Option B — GitHub integration (recommended):
1. Push branch to GitHub
2. Vercel → New Project → Import repo `kolavet`
3. Framework preset: **Astro** (auto-detected)
4. Add env vars (Step 4)
5. Deploy

## Risks

| Risk | Mitigation |
|------|------------|
| `output: 'hybrid'` breaks static pages | Test `astro build` locally after adapter install before deploying |
| Keystatic Cloud free tier limits | Check limits at keystatic.cloud before switching; fallback is GitHub OAuth with local storage |
| `KEYSTATIC_SECRET` leaked | Generate fresh value; never commit `.env.local` |
| MailerLite group ID wrong | Test with a personal email first |
